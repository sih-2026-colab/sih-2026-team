# Reusable material library

Materials are embedded in the generated blend and created by setup. Append them
from that blend's Material section when replacing assets. Names: VEHICLE_SILVER,
DARK_GLASS, TYRE, WEATHERED_ASPHALT, DRY_SOIL, GRAVEL_SHOULDER, VEGETATION,
PLASTER, CONCRETE, ACTOR_PAINT, HUD_WHITE, PATH_SELECTED, PATH_REJECTED,
PATH_SAFE, TRACK_YELLOW, EGO_TRACE, CRUISE, REPLAN, BRAKE.

All are lightweight procedural/constant materials. No external textures needed.
